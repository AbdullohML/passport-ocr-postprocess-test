# Постобработка OCR паспорта РФ

## Задача и подход

Нужно принять документ, только если верны все 10 полей и паспорт действителен на 01.10.2026. Ошибка принятия дороже отказа, поэтому я выбрал осторожный порог: сложные снимки идут на повторную съемку.

Я собираю текст визуальной зоны, проверяю, не потеряна ли строка внутри рамки поля, и сверяю данные с MRZ. В MRZ проверяются контрольные цифры (веса 7–3–1), ФИО, даты, пол, номер и код подразделения. Код также проверяется по приложенному справочнику. Даты проверяются по календарю, возрасту выдачи и правилам замены паспорта в 20 и 45 лет с 90-дневным сроком. Без MRZ или при сомнении в любом поле документ отклоняется. Снимки mobile_v2 исключены: в train у них встречаются ошибки при уверенности OCR 1.0.

## Сравнение на 3000 размеченных документах

Метод                         | Первые 2000: верно / ошибка | Последние 1000: верно / ошибка
Только визуальная зона        | 1062 / 552                  | 534 / 266
MRZ и порог уверенности 0.90 | 781 / 13                    | 401 / 7
Итоговые строгие правила     | 90 / 0                      | 49 / 0

Итог: 139 верных приемов из 3000, ошибок принятия на train не найдено. Обе части train приведены для прозрачности; пороги выбирались после изучения всего train, поэтому это не независимый тест. Проверка `evaluate.py` дала те же 139 / 0; срок действия дополнительно проверен моим кодом.

## Прогноз для скрытого test

Файл `answers.jsonl` уже создан: принято 83 из 2000 документов. Мой точечный прогноз — 83 принятых, 0 ошибочных. Это не гарантия: даже при 0 ошибках среди 139 принятых на train грубая верхняя 95%-граница частоты ошибки около 2,2% (правило трех), то есть на 83 приемах возможны примерно до двух ошибок. Часть ошибок OCR согласована между визуальной зоной и MRZ, поэтому остается риск, который по этим данным нельзя надежно устранить.

Код работает на CPU без сети и без сторонних библиотек. Запуск: `python postprocess.py data/test_predictions.jsonl answers.jsonl`. Справочник подразделений: DaData / hflabs, CC BY-SA 4.0. Правила MRZ: приложение № 24 к приказу МВД № 773. Срок действия: Постановление Правительства РФ № 2267, п. 24.
